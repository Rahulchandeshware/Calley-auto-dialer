Overview
This project automates the Calley Dialer app using Selenium and Java. The automation script helps in testing and streamlining the dialer workflow.

⚙️ Tech Stack
Programming Language: Java
Testing Framework: TestNG
Automation Tool: Selenium WebDriver
BDD Framework (if applicable): Cucumber
Build Tool: Maven
Logging: Log4j
Version Control: Git & GitHub
🚀 Features
Automates login and authentication
Dials numbers automatically
Validates call logs and reports
